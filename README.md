BOOKING API

This project is a booking application. I will try to solve the double booking problem and make it safe for this kind of race condition.

The stack
PHP 8.3, Laravel 11, MySQL 8
Pest for testing
Docker + docker-compose
GitHub Actions — tests, Pint, Larastan on every push
Laravel Pint (code style) and Larastan (static analysis, level 6)
Sanctum for API auth
Deployed on a Hetzner VPS

Status: in development
